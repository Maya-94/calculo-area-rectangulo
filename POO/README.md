# Dashboard POO – Gestor de Tareas

## Autor
María Pianda

## Descripción del proyecto

Este proyecto corresponde a la adaptación de un sistema base de Programación Orientada a Objetos (POO), cuyo objetivo es crear un Dashboard personalizado para la gestión de tareas relacionadas con la materia.

El sistema fue desarrollado en Python utilizando conceptos fundamentales de la Programación Orientada a Objetos como:

- Clases
- Objetos
- Métodos
- Constructor
- Encapsulamiento

El archivo principal modificado es `Dashboard.py`, donde se implementó un gestor de tareas que permite agregar, visualizar y eliminar actividades.

---

## Objetivo

Adaptar el proyecto original a necesidades personales, creando un Dashboard funcional que permita organizar tareas académicas, aplicando los principios de POO.

---

## Funcionalidades

El sistema permite:

- Agregar tareas
- Visualizar tareas registradas
- Eliminar tareas
- Salir del programa

Todo esto se gestiona desde un menú interactivo en consola.
